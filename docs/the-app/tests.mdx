## Legend

- **Type**:
  - `Both`: Available in both Hetero and Auto modes
  - `Hetero`: Only available in Hetero mode
- **Group**: Indicates if the test belongs to a specific test group/sequence
- **Hetero Instruction**: Instruction given when another person is conducting the test
- **Auto Instruction**: Instruction given when the patient is testing themselves
