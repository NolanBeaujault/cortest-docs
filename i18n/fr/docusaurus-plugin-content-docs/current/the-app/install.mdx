# Install the App

To install CORTEST on your Android device:

1. Download the APK from [GitHub Releases](https://github.com/NolanBeaujault/cortest-api/releases).
2. Transfer it to your phone or download directly.
3. Allow installation from unknown sources in your Android settings.
4. Open the APK and follow the instructions.

⚠️ Currently, CORTEST is only available for Android devices.
